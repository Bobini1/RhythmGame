    Detailed Description

    StandardGameplayFlow and StandardGameplayInput already include this component. Use it separately only when supplying your own gameplay input handling. Bind gameplay to the current context and disable the item while inactive.

    Hold Start and turn the scratch to change noteScreenTimeMillis. Hold Select and turn the scratch to adjust lane cover, lift or hidden cover. Lane cover takes priority when enabled. Otherwise, the enabled lift or hidden cover is adjusted. When both are enabled, a short Start+Select press switches between them. Double-press Start within 500 milliseconds to toggle lane cover while preserving note speed where the duration limits allow it.

    Settings are saved in each player's profile. Battle uses a separate profile for each side. In double play, either side adjusts the same player's settings, and Start or Select on either side can modify either scratch. Holding both buttons suspends adjustments so the retry gesture can be used.
