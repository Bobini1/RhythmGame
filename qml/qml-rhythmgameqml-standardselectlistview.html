    Detailed Description

    Set controller and supply a delegate. The model is already bound to the controller's entries. A delegate receives modelData for the entry and index for its row; use ListView.isCurrentItem for highlighting. The list handles arrows, the mouse wheel, bound controller navigation, folder focus restoration and preview movement. Call activate with the row's index when it is clicked. Return, Enter and Right open the current entry; Left goes back. Movement wraps at the ends.

    Style and size this item like any ListView. Keyboard focus still belongs to the theme: set focus on this list and its enclosing focus scopes. Use StandardSelectController directly for a custom wheel instead.

    See the selection lesson for a delegate that labels folders, charts, tables and courses.

    Property Documentation

    controller : StandardSelectController [required]

    Controller that supplies entries and actions for this list.


    Method Documentation

    activate(index = currentIndex)

    Focuses, selects and opens the row at index, or the current row when omitted. Returns false for an invalid row or disabled input. Otherwise returns the result of StandardSelectState::goForward.
