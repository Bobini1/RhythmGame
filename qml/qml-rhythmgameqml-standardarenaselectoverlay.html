    Detailed Description

    Place this component in a selection screen. It appears while seated in an Arena room, including reconnection. Bind navigationFocusTarget to the song list so closing chat can return keyboard focus there.

    Pressing Start twice on the same player side toggles ready. Set readyShortcutEnabled to false to provide your own ready input. The panel uses readyShortcutDescription for its hint. Replacing panelComponent keeps the shortcut. Hidden or disabled overlays do not handle ready input.

    A custom Ready button calls toggleReady and binds its enabled state to canToggleReady. Use ready for its label or check state and readyDisabledReason for a hint. The button and double-Start gesture use the same rules, including cancelling readiness. Disabling the shortcut leaves the public action available.

    The panel supplies its own chat tab. The chat shortcut is disabled by default because some selectors use F8 for another action. Set chatShortcutEnabled to true to enable it. Replace panelComponent to supply your own room UI.

    Property Documentation

    canToggleReady : bool [read-only]

    Whether a button or gesture can change readiness now.


    navigationFocusTarget : Item

    Receives keyboard focus after chat closes. Defaults to the parent item.


    ready : bool [read-only]

    Whether the local player is ready or the round is already being prepared.


    readyDisabledReason : string [read-only]

    Explains why readiness is unavailable. Empty when the room permits the action.


    readyShortcutDescription : string [read-only]

    Describes the ready gesture. Empty when readyShortcutEnabled is false.


    readyShortcutEnabled : bool

    Enables the double-Start ready gesture while the overlay is presented.


    Method Documentation

    toggleReady()

    Toggles readiness for a button or custom gesture. Returns false when unavailable.
