    Detailed Description

    Declare required property CourseResultContext result on a course result screen. The game selects the course result separately from the normal result. A theme can provide one screen or both, with a separate contract for each.

    StandardResultInput can close a course summary. Single-chart retry is unavailable because the result describes the whole course. The game owns this context and its data; do not destroy them from the theme.

    Property Documentation

    charts : list<ChartData> [read-only]

    Chart metadata in stage order. A saved course can contain null entries for charts no longer installed. Keep those stages in the display: their identifiers remain in course.chartIds at the same indices. Rg.tables.search(identifier) can supply a title from a table; otherwise display the identifier. Installed metadata remains valid for this context's lifetime, even if the library changes.


    course : var [read-only]

    Completed course definition.


    players : list<CourseResultPlayer> [read-only]

    Contains one or two CourseResultPlayer entries. Each pairs a profile with an aggregate course score.
