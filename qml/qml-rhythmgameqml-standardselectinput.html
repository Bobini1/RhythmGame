    Detailed Description

    The component extends StandardSelectNavigation with activation, autoplay, replay, sorting and leaving selection. Use StandardSelectNavigation alone if you only need movement. StandardSelectController already includes both.

    The bound controller keys work on either player side:

    InputAction
    Keys 1 and 3Activate the focused item.
    Key 5Start autoplay.
    Key 7Open the selected replay.
    Key 6Cycle newest, best score, best clear and best combo.
    Keys 2 and 4 at the rootCycle the sort mode backward or forward.
    Keys 2 and 4 below the rootGo back.
    Scratch directionsEmit moveRequested.
    EscapeLeave selection or the current Arena room.

    Autoplay calls StandardSelectState::openAutoplay unless tryAutoplayAction handles it first. On folders, the autoplay key enters the folder. Replay calls StandardSelectState::openReplay unless tryReplayAction handles it first. Key 6 calls StandardSelectState::cycleReplayType unless cycleReplayTypeAction is supplied.

    Keyboard arrows must come from the focused visual item. Forward presses and releases to handleUpPressed, handleDownPressed and handleReleased. Assign selectState for standard activation and back behavior. For your own browsing state, supply activateAction, goBackAction and atTopLevel. Assign actions to a StandardSelectActions instance for Escape, or disable it with exitEnabled. StandardArenaSelectOverlay supplies Arena ready input.

    Property Documentation

    actions : StandardSelectActions

    Shared selector actions. Defaults to the supplied state's actions.


    activateAction : var

    Calls activateAction() in place of focused-item activation.


    atTopLevel : bool

    Controls whether sort-key handling is currently at the top selection level.


    cycleReplayTypeAction : var

    Calls cycleReplayTypeAction() instead of StandardSelectState::cycleReplayType.


    exitEnabled : bool

    Controls the Escape shortcut for leaving selection or its Arena room.


    goBackAction : var

    Calls goBackAction() in place of leaving the current entry.


    selectState : StandardSelectState

    Standard selection state that receives activation and history actions.


    tryAutoplayAction : var

    Called as tryAutoplayAction(). Return true to handle the request, or false to continue with the standard action.


    tryCycleSortModeAction : var

    Called as tryCycleSortModeAction(delta). Return true to handle the request, or false to continue with the standard action.


    tryReplayAction : var

    Called as tryReplayAction() to choose and open a replay. Return true when handled. Return false to continue with StandardSelectState::openReplay.
