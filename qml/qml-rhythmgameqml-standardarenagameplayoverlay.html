    • gameplay : GameplayContext

    Detailed Description

    Bind gameplay to the screen's supplied context. The overlay stays hidden for local play and courses. F8 switches between standings and chat while this screen is active. Set chatShortcutEnabled to false to use your own input, or replace panelComponent to draw another panel.

    Property Documentation

    gameplay : GameplayContext [required]

    Supplies the gameplay context for this screen.
