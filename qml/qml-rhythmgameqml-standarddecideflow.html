    Detailed Description

    Bind gameplay to the GameplayContext supplied to the screen. The same property supports a single chart or a course. Your theme draws the title and other details, while the component handles input and the timeout.

    The default controls are:

    InputOperation
    Return, Enter, left click or any play keystart
    Escape, right click or Start+Selectcancel
    The timeoutMillis delay expiresstart

    The pointer area fills the parent. Set pointerEnabled to false when your theme has its own buttons, and call start or cancel from those buttons. Only the first transition request is accepted. If the standard transition fails, the component accepts another attempt.

    Starting replaces decide with gameplay, passing along the same context. Cancelling returns to the previous screen. The game keeps the play objects alive for the screen that needs them and destroys them when that screen leaves. The theme must not destroy them itself.

    A replacement startAction or cancelAction handles the whole transition. The standard action does not run afterward. See the decide lesson for an installable example.

    Property Documentation

    cancelAction : var

    Calls cancelAction() to handle the whole cancel transition.


    controllerEnabled : bool

    Controls whether BMS-controller input is active.


    gameplay : GameplayContext

    Supplies the GameplayContext received by the decide screen.


    keyboardEnabled : bool

    Controls whether keyboard input is active.


    pointerEnabled : bool

    Controls whether pointer input is active.


    startAction : var

    Calls startAction() to handle the whole start transition.


    timeoutMillis : int

    Sets the delay in milliseconds before starting automatically. Use zero to disable the timeout.


    Method Documentation

    cancel()

    Returns to the previous screen. Returns false when disabled, already transitioning, or the standard navigation fails. A replacement cancelAction counts as handled and returns true.


    start()

    Opens gameplay with the supplied context. Returns false when disabled, missing gameplay, already transitioning, or the standard screen cannot open. A replacement startAction counts as handled and returns true.
