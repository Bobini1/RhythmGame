    Detailed Description

    StandardSelectState already uses this component. Use it directly only for custom browsing. It stores folder contents, history and preview paths; your code decides when to load them, sort them and choose a focused row.

    The resolve... methods return data without changing folderContents or historyStack. Call commitFolderContents and update the history together when the navigation is ready to take effect.

    To supply custom table courses, set tableCoursesProvider to a function that accepts a tableItem and returns its course list.

    Property Documentation

    folderContents : var

    Raw contents of the current folder, table, level, or search.


    historyStack : var

    History entries in navigation order. The root folder is an empty string. StandardSelectState also uses table and level values, ChartData for a song's chart directory, and objects with a searchQuery field for searches.


    previewFiles : var

    Preview-file data loaded for the current contents.


    tableCoursesProvider : var

    Called as tableCoursesProvider(tableItem) to return a custom list of courses.


    Method Documentation

    commitFolderContents(contents)

    Replaces folderContents with a copy of contents and returns true. Null or undefined returns false without changing the current contents. Update historyStack separately when navigation succeeds.


    folderForHistoryItem(item)

    Resolves a history item to the folder it represents.


    resolveChartDirectory(directory)

    Returns the chart entries in directory.


    resolveFolderContents(item)

    Returns raw entries for folder, table or level item. An empty string opens the root. Returns an empty list for an empty folder, or null for an unsupported item. Does not change history or folderContents.


    resolveSearchResults(query)

    Returns search results for query.
