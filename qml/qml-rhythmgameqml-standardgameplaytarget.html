    Detailed Description

    Bind gameplay to the screen context and choose playerIndex for battle. The component follows the player's score-target settings. It loads saved scores for each course stage, chooses the best or latest run, and advances recorded targets as the player consumes notes. Scores without a recording use their final score rate multiplied by the points available so far.

    Battle uses the other player's current score. Arena uses the session's opponent target, and available is false until that target is available. Local play uses mode and fraction. Overriding either changes this target display without changing the player's saved settings.

    Bind a graph or label to points and finalPoints. The bestPoints, bestFinalPoints and bestMaxPoints properties describe the personal best independently of the chosen target. The component draws nothing. Pending queries are cancelled when the stage changes or it is disabled.

    Property Documentation

    available : bool [read-only]

    Whether the current target can be displayed.


    bestFinalPoints : real [read-only]

    Final points from the personal best, or zero before scores are loaded.


    bestMaxPoints : real [read-only]

    Maximum points for the personal-best score.


    bestPoints : real [read-only]

    Personal-best points at the current progress, using a recording when present.


    finalPoints : real [read-only]

    Final target points. Live battle opponents have no fixed final target.


    fraction : real

    Target points as a fraction of maximum points, for example 0.8 for 80%. Used by ScoreTarget.Fraction and when a saved target is unavailable.


    gameplay : GameplayContext

    Supplies the context for a single chart or course.


    loading : bool [read-only]

    Whether the selected player's saved scores are being loaded.


    mode : int

    ScoreTarget.Fraction, ScoreTarget.BestScore, ScoreTarget.LastScore or ScoreTarget.NextRank. Defaults to the player's saved choice. An override affects this display only and does not save a profile setting.


    playerIndex : int

    Player whose profile and progress are used. Zero selects the first player.


    points : real [read-only]

    Current target points, at the player's progress through the chart.
