    Detailed Description

    Handle moveRequested to move your list or wheel. Negative steps means up, and positive means down. repeated is true after the first movement from a held key or classic scratch. analog identifies movement accumulated from analog scratch ticks or the mouse wheel.

    The theme keeps the focused row and chooses whether to wrap, stop at an end or animate the movement. The component only tracks held input and repeat timing.

    Use StandardSelectInput to add the standard selection actions. Call pressDirection, navigate and releaseDirection directly when adapting another input source. Forward wheel events from your view to handleWheel. Disabling the component calls reset to clear held keys and accumulated scratch and wheel movement.

    Property Documentation

    analogTicksPerStep : int

    Number of analog scratch ticks required for one logical step.


    initialRepeatDelayMillis : int

    Delay before classic-scratch repeat begins, in milliseconds.


    repeatDelayMillis : int

    Delay between repeated classic-scratch steps, in milliseconds.


    Signal Documentation

    moveRequested(int steps, bool repeated, bool analog)

    Requests relative focus movement by steps. repeated identifies held input and analog identifies analog scratch or mouse wheel input.

    Note: The corresponding handler is onMoveRequested.


    Method Documentation

    handleWheel(event)

    Converts a vertical wheel event into row movement. Accumulates small deltas and moves one row per wheel notch. Returns true and accepts the event when handled, including a partial step. Returns false when disabled or when the event has no vertical movement.


    navigate(tickNumber, tickType, up, key)

    Converts tickNumber and tickType for directional key into a movement request. up selects the movement direction.


    pressDirection(key)

    Records that directional key was pressed.


    releaseDirection(key, up)

    Records that directional key was released; up identifies its direction.


    reset()

    Clears held keys, accumulated scratch and wheel movement, and repeat timing.
