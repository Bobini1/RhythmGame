    Detailed Description

    Bind result to the screen's ResultContext. The panel appears only while its round matches the session's presented result. Local results and saved scores have no round ID and do not show the panel. Course summaries use CourseResultContext and do not need this component.

    F8 switches between standings and chat. A theme can replace panelComponent while keeping placement and chat behavior, as Default does for its result design. StandardResultInput blocks Return confirmation while this result's chat is open. Custom result input should apply the same rule.

    Property Documentation

    result : ResultContext

    Supplies a chart result, or null when no chart result is presented.
