    CourseResultPlayer QML Type

    Profile and aggregate score paired within a course summary. More...

    Properties

    Detailed Description

    Read these objects from CourseResultContext::players. The game supplies each object and keeps it alive with its result context.

    Property Documentation

    profile : Profile [read-only]

    Participant's profile.


    score : BmsScoreCourse [read-only]

    Aggregate BmsScoreCourse, including individual stage scores. Totals are in score.result. Replay events and gauge history combine the recorded stages for use in graphs. Check for missing replay or gauge data on imported scores.
