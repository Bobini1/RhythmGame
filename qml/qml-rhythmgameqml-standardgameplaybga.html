    StandardGameplayBga QML Type

    Draws the current stage's background animation and miss layer. More...

    Import Statement: import RhythmGameQml
    • List of all members, including inherited members

    Properties

    • gameplay : GameplayContext

    Detailed Description

    Bind gameplay and give the item a size. It connects the four BGA layers to video outputs and follows course stage changes. The two overlay layers treat black as transparent. A Bad or Poor judgement shows the miss layer for 400 milliseconds. Image proportions and relative layer sizes are kept.

    Visibility follows the player's bgaOn setting, or the main profile's setting in battle. Override visible to choose differently. This item is optional; themes can instead connect gameplay.bga.layers to their own video sinks.
