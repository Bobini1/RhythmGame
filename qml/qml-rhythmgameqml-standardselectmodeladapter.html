    Detailed Description

    Supply a list in source and the number of rows needed in minimumCount. If the source is already long enough, entries contains it unchanged. Otherwise, complete copies of the list are repeated until the minimum is met. An empty source produces null placeholders, with at least one row. These placeholders belong only to the presentation model.

    Repeated entries still refer to the same items. The adapter doesn't clone objects or track focus. A normal list can use StandardSelectState::entries directly without this adapter.

    Property Documentation

    entries : var [read-only]

    Contains repeated source entries, or null placeholders for an empty source.


    minimumCount : int

    Sets the minimum number of rows needed by the view.


    source : var

    Supplies the source list, with one entry per item.
