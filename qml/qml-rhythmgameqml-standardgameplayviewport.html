    Detailed Description

    Bind player and chartData to the current stage, and set noteHeight to the distance from the top clipping edge to the judgement line. Use pixelsPerBeat to place notes relative to player.position. The component updates the player's filtered note and bar-line models when the dimensions, profile settings or stage change.

    Speed follows the profile's noteScreenTimeMillis and HiSpeedFix setting. Off uses 120 BPM. Main, Start, Min, Max and Avg use the corresponding chart BPM. BPM and scroll changes within the chart still affect note movement.

    A field with lane cover or lift should set visibleHeight to the distance from the lane cover to the judgement line. Hidden cover does not reduce this distance for speed calculation. barLineHeight can describe a separate clipped area for bar lines. All heights use the renderer's local coordinates. The component draws nothing and does not occupy layout space.

    It owns the calls to GameplayState::setVisiblePositionSpans() for the player. Fields sharing a player, such as two sides in double play, share the filtered models and must use the same visible position spans.

    Property Documentation

    barLineHeight : real

    Height used to draw bar lines. Defaults to noteHeight.


    chartData : ChartData [required]

    Metadata for the chart currently playing, including a course stage.


    noteHeight : real [required]

    Distance from the top note clipping edge to the judgement line.


    pixelsPerBeat : real [read-only]

    Distance for one unit of notePosition or player.position. Zero for an empty field.


    player : Player [required]

    Player whose settings and filtered note models are used.


    visibleHeight : real

    Note travel distance after lane cover and lift. Defaults to noteHeight.
