    Detailed Description

    Place this component directly inside a multiplayer screen. If it is nested in another container, set screen to the screen root. Use session for the room list, createRoom(), joinRoom() and retry(); their arguments are listed in the ArenaSession reference. Call close from the Back button. Removing the browser disconnects from Arena.

    Joining a room opens the configured selector on the ordinary screen stack. StandardSelectController returns to the browser when the room is left. Prepared charts open gameplay even while another screen, such as Settings, covers the selector. The theme requests its start after its intro, and Arena waits for every participant before releasing playback. Closing gameplay returns to the retained screen.
