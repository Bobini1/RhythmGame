    • isPlayKey(key)

    Detailed Description

    Call isPlayKey when a custom handler needs the same check as decide or result input. The singleton recognizes Col11 through Col17 and Col21 through Col27. It excludes Start, Select, scratch directions and ordinary keyboard or function keys.

    Method Documentation

    isPlayKey(key)

    Returns whether key is a standard player-one or player-two play key.
