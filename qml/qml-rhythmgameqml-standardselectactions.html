    Detailed Description

    StandardSelectState already includes this component. Use it separately if your theme implements its own browsing state. openPlayable uses the current solo or battle profiles outside Arena. Replays use the main profile alone. In an Arena room it submits the chart choice to the session, and it handles a course choice without opening it.

    A true return from openPlayable means the request was handled. It does not guarantee that gameplay opened. Unsupported items return false.

    Set tryOpenPlayableAction to handle a request before the standard action. The function receives item, autoplay, replay, replayScore. Return true when it handles the request, or false to continue with the standard action.

    Call exit to leave selection. In Arena it leaves the room first, then returns to the browser. A room lost while another screen is open returns to the browser when selection becomes active again. Disabling this component suspends navigation and input.

    StandardArenaSelectOverlay supplies the Arena ready controls and shortcut.

    Property Documentation

    Method Documentation

    cancelScoreLoading()

    Cancels a pending saved-result or replay action.


    exit()

    Leaves the room in Arena, or closes local selection. Folder history is separate.


    openPlayable(item, autoplay = false, replay = false, replayScore = null)

    Opens installed chart or course item. autoplay selects automatic play; replay selects a saved recording. Both default to false. replayScore accepts a cached result or full score and defaults to null. A replay needs recording data; a score without replay selects its saved note pattern for G-Battle. Do not combine autoplay and replay.

    Uses the active solo or battle profiles. Replay always uses the main profile alone. In Arena, manual chart activation proposes the chart; courses, autoplay and replay are handled without starting local play. True means the request was handled, including a rejected course or an asynchronous load. It does not guarantee that gameplay opened.


    openResult(item, score)

    Opens score for chart or course item using the main profile. Supply a cached BmsResult/BmsResultCourse or a full BmsScore/BmsScoreCourse belonging to that profile. Cached results are loaded before opening.

    Returns false for unsupported input, inactive selection or Arena. For an asynchronous load, true means the request was accepted; it does not guarantee the result screen has opened. loadingScore tracks the wait, and cancelScoreLoading cancels it.
