    Detailed Description

    Declare required property ResultContext result on a normal result screen. The game supplies the completed chart and scores when it opens the screen. Chart metadata and totals stay fixed after a course advances, although online score submission state can still change.

    Bind the context to StandardResultInput::result for confirmation and supported single-chart retry. Read the result's own metadata when showing the completed stage, since the originating play may have advanced. The game keeps the context and its scores alive while the result screen needs them. Do not destroy them from the theme.

    Property Documentation

    arenaActive : bool [read-only]

    Reports whether the Arena session still presents this result's round. Use it for standings and chat input rules, including in themes that draw their own panel. The context checks the round ID and session state, so the theme doesn't need to repeat those checks. Local results and saved scores return false.


    arenaRoundId : string [read-only]

    Identifies the Arena round for this result. It is empty for local play and saved-score views. Standard gameplay supplies it before the screen is created, so a result screen doesn't need an initialization callback from the host.


    chartData : ChartData [read-only]

    Describes the completed chart, regardless of the current gameplay stage.


    course : var [read-only]

    Contains the course definition for a stage result. It is undefined for a single chart.


    gameplay : GameplayContext [read-only]

    Refers to the originating play, or null if the result was opened without one. Standard retry uses this reference. The play remains live and may describe the next stage, so use the result's chart and stage fields for the completed stage.


    players : list<ResultPlayer> [read-only]

    Contains one or two ResultPlayer entries. Each pairs a profile with a completed BmsScore.


    stageCount : int [read-only]

    Gives the stage count of the originating play. It stays fixed and is one for a single chart.


    stageIndex : int [read-only]

    Gives the completed stage index, starting at zero. It stays fixed and is zero for a single chart.
