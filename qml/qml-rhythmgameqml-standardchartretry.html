    Detailed Description

    For a gameplay button, supply gameplay. For a normal result button, supply result. StandardGameplayInput and StandardResultInput already use this component internally.

    retry replaces gameplay and any result above it without opening selection or decide. The game destroys the old play with the old screen. An unfinished attempt is not saved, and a result that was already saved is kept.

    Standard retry is available for manual single-chart play. It excludes courses, autoplay, replay, battle and Arena. Check available before offering a custom retry button. A course summary never offers single-chart retry.

    Property Documentation

    available : bool [read-only]

    Reports whether the current screen and runner support standard retry.


    gameplay : GameplayContext

    Supplies the gameplay context when retry is offered during play.


    result : QtObject

    Supplies the result context. Course summaries do not support chart retry.


    Method Documentation

    retry(samePattern)

    Retries with the same pattern when samePattern is true, or fresh randomization otherwise. Returns false when disabled or unsupported. A supported request is consumed even if loading fails; in that case the current screen remains. No call to finish() is made.
