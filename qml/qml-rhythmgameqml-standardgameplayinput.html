    Detailed Description

    Use StandardGameplayFlow for a complete gameplay screen. It already includes this component. Use StandardGameplayInput separately only when your theme supplies its own gameplay flow. Handle exitRequested to leave gameplay or finish the stage. This component does not save scores or open results. It includes StandardGameplaySpeedControls. Set speedControlsEnabled to false when supplying different speed or cover input handling.

    Hold Start+Select for retryHoldDurationMillis to enter retryChoosing. Release Start for the same pattern, Select for fresh randomization, or both to cancel. While choosing, exit is blocked. Delay completion and disable your other controls with !retryChoosing, but leave this component enabled so it can receive the releases.

    retryEnabled and exitEnabled disable the corresponding methods and input mappings. retryAction replaces restarting, and retry can also be called by a button. Standard retry excludes courses, autoplay, replay, battle and Arena. Use StandardChartRetry if you only need the retry operation.

    Property Documentation

    exitEnabled : bool

    Controls whether Escape and calls to exit are accepted.


    gameplay : GameplayContext

    Supplies the GameplayContext received by the gameplay screen.


    retryAction : var

    Calls retryAction(samePattern) in place of restarting.


    retryAvailable : bool [read-only]

    Whether a retry button or gesture can request a supported restart now.


    retryChoosing : bool [read-only]

    Reports whether the Start+Select gesture is waiting for a release choice.


    retryEnabled : bool

    Controls whether retry and the Start+Select gesture are enabled.


    retryHoldDurationMillis : int

    Start+Select hold duration before choosing a retry, in milliseconds.


    speedControlsEnabled : bool

    Enables StandardGameplaySpeedControls. Disable when supplying your own speed/cover input.


    Signal Documentation

    exitRequested()

    Emitted by Escape or exit. The owning flow decides how to leave.

    Note: The corresponding handler is onExitRequested.


    Method Documentation

    cancelRetry()

    Cancels the hold/release choice.


    exit()

    Emits exitRequested() if exit input is allowed.


    retry(samePattern)

    Retries with the same pattern if samePattern is true, or a fresh one.
