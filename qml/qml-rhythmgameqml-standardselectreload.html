    • reload(focusedItem, history, folderPath)

    Detailed Description

    StandardSelectState and StandardSelectController already include this behavior. Use the component separately when writing your own selector.

    Call reload with the focused item, browsing history and folder path. A true return means a reload or scan was requested. A false return means the caller should refresh its current folder contents instead. The caller keeps responsibility for navigation and focus.

    Method Documentation

    reload(focusedItem, history, folderPath)

    Reloads the table at focusedItem or in history, or scans the root containing folderPath. Returns true when a reload or scan was requested.
