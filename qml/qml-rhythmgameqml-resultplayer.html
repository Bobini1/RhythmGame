    ResultPlayer QML Type

    Profile and score paired within a normal result. More...

    Import Statement: import RhythmGameQml
    • List of all members, including inherited members

    Properties

    • profile : Profile
    • score : BmsScore

    Detailed Description

    Read these objects from ResultContext::players. Use this player's profile for names and preferences; the main profile may belong to another player. The game supplies the object and keeps it alive with its result context.

    Property Documentation

    profile : Profile [read-only]

    Participant's profile.


    score : BmsScore [read-only]

    Completed BmsScore. Totals are in score.result. Imported scores may have no replayData or gaugeHistory; check those before drawing graphs.
