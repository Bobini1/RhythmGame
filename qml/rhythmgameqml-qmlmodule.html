RhythmGame QML types

Import RhythmGameQml to use these types. Start with the QML API reference to choose a component for your screen. The theme tutorial provides installable examples.

CourseResultContext

Completed course summary supplied to the course-result screen

CourseResultPlayer

Profile and aggregate score paired within a course summary

GameplayContext

Supplies play data to decide and gameplay screens

PendingReplyGroup

Cancels a set of asynchronous requests together

ResultContext

Supplies a completed chart result, including a course stage

ResultPlayer

Profile and score paired within a normal result

ScoreDetails

Loads replay events and gauge history for a saved score summary

StandardArenaGameplayOverlay

Shows Arena standings and chat during gameplay

StandardArenaOverlay

Places an Arena panel and saves its position and chat preferences

StandardArenaResultOverlay

Shows standings and chat for an Arena result

StandardArenaSelectOverlay

Shows the Arena room, ready controls and chat on song selection

StandardChartRetry

Restarts a supported play without choosing an input gesture

StandardDecideFlow

Starts or cancels play from a decide screen

StandardGameplayAttemptState

Reports whether either player has made a scoring hit

StandardGameplayBga

Draws the current stage's background animation and miss layer

StandardGameplayFlow

Starts play, handles exit and retry, saves scores and opens results

StandardGameplayInput

Maps gameplay exit, retry, and speed and cover adjustments

StandardGameplaySpeedControls

Adjusts note speed and covers with Start, Select and scratch input

StandardGameplayTarget

Supplies the score target and personal best for a gameplay display

StandardGameplayViewport

Applies the player's note speed and keeps visible note models in sync

StandardInputKeys

Identifies bound lane keys used by the standard screen controls

StandardMainActions

Opens the standard destinations from a main menu

StandardMainController

Supplies main-menu actions, Start input and background music

StandardMultiplayerFlow

Connects the Arena browser and opens room selection and gameplay

StandardRanking

Loads a chart's online ranking and opens its ranking website

StandardResultInput

Handles Continue and Retry actions on a result screen

StandardSelectActions

Opens playable selections and handles leaving selection

StandardSelectController

Adds browsing, input, previews and music to a song selector

StandardSelectInput

Maps bound selection actions and forwards movement requests

StandardSelectListView

Connects a finite song list to a selection controller

StandardSelectModelAdapter

Repeats entries to fill the visible rows of a circular selector

StandardSelectNavigation

Converts directional keys, scratch and mouse wheel input into row movement

StandardSelectOptions

Provides optional translated labels for sorting and replay choices

StandardSelectPreview

Plays the focused chart's preview after a short delay

StandardSelectReload

Reloads a table or scans the root folder containing the current song

StandardSelectSession

Loads folder contents and stores browsing history

StandardSelectShortcuts

Adds F2, F3, F11 and F12 actions to a selector

StandardSelectState

Tracks browsing, focus and saved choices for a song selector
