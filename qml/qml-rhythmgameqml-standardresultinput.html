    Detailed Description

    Bind result to the supplied ResultContext or CourseResultContext. The component draws no controls. A Continue button calls confirm and binds its enabled state to acceptsInput && confirmEnabled. See the result lesson for complete screens.

    Confirm or close

    Input waits for inputDelayMillis after the screen becomes active. acceptsInput reports when this delay has passed.

    Return and confirm also require confirmEnabled. By default this is false while the matching Arena result's chat is open, so Return sends a message without closing the result. Escape and close bypass that confirmation rule, but still wait for the input delay.

    controllerEnabled controls bound game buttons independently of Return, Escape and calls from your own buttons. Start closes the result. Other bound keys first call tryHandleButtonAction, then try retry, then close for a standard play key. Use that callback for actions such as cycling gauges.

    Retry a chart

    Bind retry buttons to retryAvailable. Call retry with false for a new random pattern or true for the same pattern. Bound keys 5 and 7 use these same actions on either player side.

    Standard retry is unavailable for courses, autoplay, replay, battle and Arena. tryRetryAction can handle a request before StandardChartRetry. closeAction replaces closing the result entirely. Return true from a try...Action callback when it handled the request; return false to let the standard action continue.

    Property Documentation

    acceptsInput : bool [read-only]

    Reports whether result input currently accepts actions.


    closeAction : var

    Calls closeAction() in place of closing the result.


    confirmEnabled : bool

    Enables keyboard and pointer confirmation. Defaults to false while this result's Arena chat is open.


    controllerEnabled : bool

    Controls whether BMS-controller input is active.


    inputDelayMillis : int

    Delay before result input becomes active, in milliseconds.


    result : QtObject

    Supplies the ResultContext or CourseResultContext received by the screen.


    retryAvailable : bool [read-only]

    Whether a supported retry can be requested now, including the input delay.


    retryEnabled : bool

    Controls retries from both buttons and bound controller input.


    tryHandleButtonAction : var

    Called as tryHandleButtonAction(key). Return true to handle the request, or false to continue with the standard action.


    tryRetryAction : var

    Called as tryRetryAction(samePattern). Return true to handle the request, or false to continue with the standard action.


    Method Documentation

    close()

    Closes the result screen when input is accepted.


    confirm()

    Confirms and closes from keyboard or theme-provided pointer input.


    handleButton(key)

    Handles a standard result-screen key.


    retry(samePattern)

    Retries with the same pattern when samePattern is true, or fresh randomization otherwise.
