    Detailed Description

    Each option has a stable value and a translated text. Use the value when changing a setting. Labels and list positions are not identifiers. The labels update when the game language changes.

    StandardSelectState exposes these choices through its display properties. You can also use this singleton directly, for example in Settings. It does not read or change profile settings, sort entries, or choose a replay. Themes can use their own text, models or artwork instead.

    To customize a label, format it in the theme's binding or build a separate model. Compare the stable value, not its position in the list. For example, a ComboBox can use this model with textRole set to text and valueRole set to value:

    model: selection.replayOptions.map(option => ({
    value: option.value,
    text: option.value === StandardSelectState.BestCombo
        ? qsTr("Longest combo") : option.text
}))

    Property Documentation

    replayOptions : var [read-only]

    Replay choices as value, text objects.


    sortOptions : var [read-only]

    All sort choices as value, text objects in the default cycle order. Total sorts by the chart's TOTAL gauge value, not its note count.


    Method Documentation

    replayText(type)

    Returns the display label for type, or an empty string for an unknown value.


    sortText(mode)

    Returns the display label for mode, or an empty string for an unknown value.
