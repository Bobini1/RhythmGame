    Detailed Description

    Use this component when a graph or other display needs more than the points and clear type in a cached result. Set result to a BmsResult or BmsResultCourse from the profile's score database, and set profile to the score's owner. The profile defaults to the main profile.

    Selection exposes summaries through StandardSelectState::results. Other screens can read profile.scoreDb.chartResults[md5.toUpperCase()] or profile.scoreDb.courseResults[identifier]. Each value is a list of summaries; use an empty list when the key is absent.

    score is null while loading or after failure. When ready, it contains a BmsScore or BmsScoreCourse. Check its replayData and gaugeHistory separately: an imported score can be ready without either. A course score includes individual stage scores and combined data for graphs.

    Place the component inside the screen or panel that needs it. Changing result or profile, disabling it, or destroying it cancels its request. Other consumers of the same score keep their requests. Saves and imports refresh the data automatically. Call reload to retry after an error.

    Display the loading state

    StatusWhat to show
    ScoreDetails.IdleResult or profile is missing, or the component is disabled.
    ScoreDetails.LoadingA loading message; score is null.
    ScoreDetails.ReadyThe score, with separate messages for missing graph data.
    ScoreDetails.ErrorA failure message and a button calling reload().

    See the chart details example for a graph that distinguishes these states.

    Property Documentation

    loading : bool [read-only]

    Whether the requested score is loading.


    profile : Profile

    Profile whose database contains result.


    result : var

    Result to load, or null when no saved run is selected.


    score : var [read-only]

    Loaded score, or null while disabled, loading, or after failure.


    status : int [read-only]

    Current loading state. Ready does not imply a recording exists.
