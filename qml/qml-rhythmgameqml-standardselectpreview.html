    Detailed Description

    StandardSelectController includes this component as its preview property and coordinates it with background music. Customize that property instead of adding a second preview player.

    For a custom selector, set selectState to a StandardSelectState. The component uses its focused chart and discovered preview file. Without a preview file, it plays the chart's audio through ChartAudioPlayer, which does not load BGA. Set chartAudioEnabled to false to omit that fallback. For custom browsing, supply chartData and previewSource directly.

    Bind moving to your list's movement state to wait until scrolling stops. Changing the source cancels the previous load and starts the delay again. Disabling the component stops audio and clears its sources. Bind a theme's background music to the inverse of playing if it should stop during previews, for example screen.enabled && !preview.playing.

    Property Documentation

    chartAudioEnabled : bool

    Allows audio-only chart playback when no preview file is present.


    chartData : ChartData

    Chart to preview. Follows the selection unless supplied directly.


    delayMillis : int

    Delay after the source changes or scrolling stops, in milliseconds.


    fadeInMillis : int

    Fade-in duration for either kind of preview, in milliseconds.


    moving : bool

    Delays a pending preview while the theme's list is moving.


    playing : bool [read-only]

    Whether loaded preview audio is currently playing.


    previewSource : string

    Preview file or song-asset source. Empty enables the chart-audio fallback.


    selectState : StandardSelectState

    Supplies the current chart and preview paths. Optional for custom browsing.


    volume : real

    Playback volume, from zero to one.
