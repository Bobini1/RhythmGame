# 05-select

Copy the whole `05-select` directory into your game's `themes` directory and restart the game.
In Settings > Themes, choose `05-select` for the screen roles listed in `theme.json`.
Keep Default selected for roles the example does not provide.

Read the lesson at [the tutorial source](https://github.com/Bobini1/RhythmGame/blob/master/docs/pages/theme-tutorial/05-select.md).
The generated tutorial includes the code snippets and a ZIP download of this directory.

The examples use the theme API in the same source revision as the tutorial.
Older game builds without GameplayContext, ResultContext and CourseResultContext cannot run the later lessons.
