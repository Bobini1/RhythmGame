# 07-gameplay

Copy the whole `07-gameplay` directory into your game's `themes` directory and restart the game.
In Settings > Themes, choose `07-gameplay` for the screens listed in `theme.json`.
Keep Default selected for screens the example does not provide.

Read the lesson
at [the tutorial source](https://github.com/Bobini1/RhythmGame/blob/master/docs/pages/theme-tutorial/07-gameplay.md).
The generated tutorial includes the code snippets and a ZIP download of this directory.

The examples use the theme API in the same source revision as the tutorial.
