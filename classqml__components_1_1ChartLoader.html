Parameters
filenameThe path to the chart file.
player1The first player profile.
player1AutoPlayWhether the first player is in auto-play mode.
player1ReplayWhether the first player is in replay mode.
score1The score to replay for the first player, optional. Incompatible with auto-play.
player2The second player profile, can be nullptr for single-player.
player2AutoPlayWhether the second player is in auto-play mode.
player2ReplayWhether the second player is in replay mode.
score2The score to replay for the second player. Incompatible with auto-play.
Returns
A pointer to the loaded chart, or nullptr on failure.

If score is not null and replay is false, the game will load the chart with the same settings the score (G-Battle).

◆ retryChart()

auto qml_components::ChartLoader::retryChart ( gameplay_logic::ChartRunner * current,
bool samePattern ) const

Creates a new runner without stopping, finishing or saving current. Same-pattern retry preserves the chart's random branches and lane transformation. Otherwise the current profile options are used. Returns nullptr when unsupported or loading fails. The caller owns the new runner; Arena eligibility and screen navigation are caller policies.
