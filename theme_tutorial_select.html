5. Browse songs and courses

Previous | Tutorial | Next: Decide

Goal: Build a song list that opens charts and courses, then add saved scores, replays and rankings.

Install docs/examples/theme-tutorial/05-select/ and choose it for Select. Keep your current themes for Main Menu, Decide and gameplay. Start with the list; the chart details panel is optional.

Download 05-select or open the source folder.

Use the standard browsing behavior

StandardSelectController loads folders and tables, remembers the path back, and opens charts or courses. It also handles input, shortcuts, background music and chart previews. The theme draws the rows, and StandardSelectListView connects the current row to the controller.

StandardSelectController {
id: selection
}

The controller opens the root folder automatically. Its entries contain one instance of each filtered item, which suits a normal list. A circular wheel can use presentationEntries to repeat entries when it needs more visible rows.

Use the complete controller once. Adding StandardSelectInput or StandardSelectShortcuts alongside it would add behavior already included by the controller. Use those smaller components when building your own browsing behavior.

Background music stops when a chart preview starts. The list waits until scrolling stops before playing a preview. Both stop when selection becomes inactive, such as during gameplay. See StandardSelectPreview to change the preview delay, volume or audio source.

Recognize the entry types

The controller's entries list contains several types. Each delegate receives one of them as modelData. Check its type before reading properties such as title or name.

Entry Type check Useful fields for a delegate What selection.goForward(item) does
Song folder typeof item === "string" The value is the folder path. You can use its last path segment as a label. Opens the folder.
Installed chart item instanceof ChartData title, subtitle, artist, playLevel, keymode, md5, path, stageFileSource Starts play, or proposes the chart in Arena.
Missing table chart item instanceof entry title, subtitle, artist, level, md5, url, urlDiff Does nothing. The table describes the chart, but the chart was not found in the song database.
Difficulty table or collection item instanceof table name, symbol, levels, courses, identifier Opens its levels and courses.
Table level item instanceof level name, entries Opens its charts. Installed charts become ChartData; missing charts remain entry.
Course item instanceof course name, chartIds, constraints, unavailableReason Requests course play. The course must be supported and all stages must be installed. Course play is unavailable in Arena.

ChartData starts with a capital letter. The names entry, table, level and course are lowercase QML value types. The example has pragma ValueTypeBehavior: Addressable at the top of the file. This is required for those instanceof checks.

The example uses one ItemDelegate and chooses its text by type. Folder, table, level and course labels identify what opening the row will do. Missing charts get a separate label, while installed charts show their title.

function labelFor(item) {
if (typeof item === "string") {
const path = item.replace(/\\/g, "/").replace(/\/$/, "");
const name = path.substring(path.lastIndexOf("/") + 1) || path;
return qsTr("Folder: %1").arg(name);
}
if (item instanceof ChartData)
return item.title || qsTr("Untitled chart");
if (item instanceof entry)
return qsTr("%1 (not installed)").arg(item.title);
if (item instanceof table)
return qsTr("Table: %1").arg(item.name);
if (item instanceof level)
return qsTr("Level: %1").arg(item.name);
if (item instanceof course)
return qsTr("Course: %1").arg(item.name);
return "";
}

The generated references list the fields on ChartData, entry, table, level and course.

Connect a list to the controller

StandardSelectListView extends ListView with the navigation needed by a song select screen. Set its controller and supply a delegate for each row.

StandardSelectListView {
id: songList
Layout.fillWidth: true
Layout.fillHeight: true
Layout.minimumHeight: 60
clip: true
focus: true
controller: selection
ScrollBar.vertical: ScrollBar {}
// [select-delegate]
delegate: ItemDelegate {
id: row
required property int index
required property var modelData
width: ListView.view.width
text: screen.labelFor(modelData)
highlighted: ListView.isCurrentItem
onClicked: songList.activate(row.index)
}
// [select-delegate]
}

The list keeps its current row and the controller's focused entry together. Up, Down and the mouse wheel move between rows, wrapping at either end. Return, Enter and Right open the current entry, and Left goes back. Bound controller input uses the same selection. Going back from a folder restores its row automatically.

Wheel input works while the pointer is over the list and changes the selected entry.

A row's click handler calls songList.activate(row.index). That method selects the row, gives the list keyboard focus and opens the entry. The list also pauses preview startup while it is moving.

Set focus: true on the list and its enclosing Pane, as the example does. This tells Qt where to send keyboard events when the screen becomes active. The chosen row and keyboard focus are separate: another button can have keyboard focus while the same song remains selected.

A delegate describes one visible row. Its modelData receives the entry, while index identifies the row. labelFor() chooses the label by type.

delegate: ItemDelegate {
id: row
required property int index
required property var modelData
width: ListView.view.width
text: screen.labelFor(modelData)
highlighted: ListView.isCurrentItem
onClicked: songList.activate(row.index)
}

Bind highlighted to ListView.isCurrentItem so the highlight follows the current row.

For a custom wheel, handle the controller's moveRequested and focusRequested signals. Call setFocused() with the row's data when the wheel chooses an entry. The controller reference describes this interface.

Handle an empty folder or selection

When browsing or filtering produces no entries, entries is [], focusedItem is null and focusedIndex is -1. The example shows a separate message above the empty list:

Label {
Layout.fillWidth: true
visible: selection.entries.length === 0
text: qsTr("No entries. Check song folders and filters.")
wrapMode: Text.WordWrap
}

A circular wheel's presentationEntries uses null placeholders when the list is empty. Check for null before reading a row's properties. Missing table charts still appear as entry objects. An unsuccessful search leaves the previous list in place.

Show the stages of a course

The example shows a stage list when a course is selected. It keeps the stage order, including repeated charts, and marks missing charts as not installed. The list scrolls within a limited height so long courses leave room for browsing.

A course's loadCharts() result contains a ChartData for each installed stage. A missing stage is a string containing its MD5 or sha256/<hash> identifier. Those strings are not folder paths.

Filter by keymode

The keymode buttons use named SelectKeymodeFilter values. SP shows 5K and 7K charts, while DP shows 10K and 14K charts. All removes the keymode filter. Folders, tables and courses remain in the list.

Flow {
Layout.fillWidth: true
spacing: 6
Repeater {
model: [
{ value: SelectKeymodeFilter.All, text: qsTr("All") },
{ value: SelectKeymodeFilter.Single, text: qsTr("SP") },
{ value: SelectKeymodeFilter.Double, text: qsTr("DP") },
{ value: SelectKeymodeFilter.K5, text: qsTr("5K") },
{ value: SelectKeymodeFilter.K7, text: qsTr("7K") },
{ value: SelectKeymodeFilter.K10, text: qsTr("10K") },
{ value: SelectKeymodeFilter.K14, text: qsTr("14K") }
]
delegate: Button {
id: keymodeButton
required property var modelData
text: modelData.text
checkable: true
autoExclusive: true
checked: selection.keymodeFilter === modelData.value
onClicked: {
selection.setKeymodeFilter(keymodeButton.modelData.value);
songList.forceActiveFocus();
}
}
}
}

Each button's checked state follows the controller's keymodeFilter. checkable and autoExclusive keep one button selected. The Flow wraps the buttons onto another row when the window is narrow.

Clicking a button calls selection.setKeymodeFilter(), which saves the choice in the active profile and updates selection.keymodeFilter. Switching profiles updates the filter to that profile's choice. Sorting and replay choices work the same way through setSortMode() and setReplayType().

These properties are read-only. Bind controls to them and use the methods to change the choice.

Use the same actions from buttons and keys

Buttons call the same controller actions as bound keys.

RowLayout {
Button {
text: qsTr("Sort: %1").arg(selection.sortModeText)
onClicked: selection.cycleSortMode()
}
Button {
text: qsTr("Autoplay")
enabled: selection.autoplayAvailable
onClicked: selection.openAutoplay()
}
}

cycleSortMode () cycles the available sort choices and saves the choice in the active profile. Bound keys 2 and 4 use the same action at the root. Inside a folder they go back. A menu that chooses a particular sort mode can call setSortMode(mode). The button displays sortModeText, the translated name of the current sort mode. "Total" means the chart's TOTAL gauge value. It does not mean the number of notes.

openAutoplay () starts the focused chart or course. autoplayAvailable keeps the button disabled for folders, incomplete courses and Arena. Bound key 5 uses the same action, and also enters folders while browsing.

Press F12 to open Settings. This uses the controller's openSettings() action. The controller also exposes reloadCurrentFolderOrTable() for F2 and openSelectedFolder() for F3. Their action overrides apply to both buttons and shortcuts.

Play a saved replay

The controller chooses a saved run using the active profile's replay setting. The choices are newest, best score, best clear and best combo. The combo box uses replayOptions. Each option has a text label and a stable value. The two role properties tell the combo box which field to display and which field to select. currentValue follows selection.replayType, and setReplayType(currentValue) saves the player's choice.

RowLayout {
ComboBox {
model: selection.replayOptions
textRole: "text"
valueRole: "value"
currentValue: selection.replayType
onActivated: selection.setReplayType(currentValue)
}
Button {
text: qsTr("Replay")
enabled: selection.replayAvailable
onClicked: selection.openReplay()
}
}

These labels are already translated; use them without qsTr(). For custom labels, see StandardSelectOptions.

The button calls openReplay (), which is also the action used by bound key 7. Bound key 6 cycles the replay choice. No extra handler is needed on the controller.

replayAvailable keeps the button disabled until a usable replay is loaded. Scores imported without replay data can still be viewed as results, but cannot be played back. A course replay needs replay data for all its stages. Replay playback uses the main profile alone and is unavailable in Arena.

Add an optional chart details panel

The panel shows the selected chart's image, saved scores and timing graph. Its chartData binding is null for folders, courses and missing table entries.

readonly property ChartData chartData: selection.focusedItem instanceof ChartData
? selection.focusedItem : null
readonly property var chartResults: selection.results[selection.focusedItem?.md5] || []

ChartData.stageFileSource is ready to use as an Image URL, including for a chart inside an archive. The example shows a small placeholder when a chart has no image. For a raw local path, use Rg.fileQuery.localFileUrl(path) instead of constructing a file:/// URL yourself.

The controller's results map holds BmsResult summaries without replay data. It updates after scores are saved or imported. StandardRanking finds the best clear and best score from these results; they can be different runs.

Label {

Use ScoreDetails when the panel needs a full score, such as replay hit events or gauge history. The example loads the latest saved result. Changing the selected result cancels the previous load, so the graph cannot show replay data for the chart you just left.

ScoreDetails {
id: scoreDetails
result: screen.chartResults[0] || null
}

The graph receives the full score's replay data and the selected chart's timing windows. It keeps the same fixed scale that the result lesson uses. A saved result can exist without a replay, so the panel distinguishes no saved score, a replay that is loading, a failed load and a score without replay data.

Include the Arena room panel

Open Multiplayer from the main menu, then join an Arena room. The game opens your configured select screen, so the same example serves local and multiplayer play. Keep Default selected for the multiplayer screen when using this example. Use Leave selection to leave the room and return to the browser.

Add StandardArenaSelectOverlay for ready controls and chat. It appears only in an Arena room. Press START twice to toggle ready. navigationFocusTarget returns keyboard focus to songList when chat closes.

StandardArenaSelectOverlay {
navigationFocusTarget: songList
}

Try a complete browsing cycle

Enter a song folder, choose a chart, and play it using your existing gameplay theme. After closing the result, the list should still show the folder you left. Use Back or Left to go up a folder, and Leave selection to leave the screen.

Try the same navigation with scratch and bound keys 1 or 3. Open an empty folder to check its message. On a chart with a saved replay, try Replay and choose another run from the combo box. If you have a course, select it and check its stage list before starting play.
